# WallDesk media

This directory contains the README's media placeholders.

Replace the placeholder SVGs with real screenshots using the same filenames:

- `home.svg` — home page with the popular wallpaper grid
- `search.svg` — search page with filters open
- `wallpaper-detail.svg` — wallpaper detail page with actions
- `downloads.svg` — local downloads library
- `collections.svg` — favorites and imported collections
- `settings.svg` — Appearance or Advanced settings
- `video-preview.svg` — thumbnail shown before the demo recording exists

Add the optional screen recording as `walldesk-demo.mp4`. Keep screenshots
free of personal API keys, local paths, usernames, and private wallpaper
collections.
